# SAVO Social Media Base Specifications

These are neutral specification-ready bases, not campaign artwork. Use the full-color mark for profile images and the appropriate outlined lockup for covers. Keep critical content inside each platform's current safe area and verify platform requirements before publishing.

| Application | Canvas | Base treatment |
|---|---:|---|
| Instagram profile | 1080 x 1080 | Centered full-color mark; circular-crop safe |
| Instagram square post | 1080 x 1080 | Ink or White base; lockup inside clear space |
| Instagram portrait | 1080 x 1350 | Neutral base; safe header/footer zones |
| Instagram Story | 1080 x 1920 | Neutral base; keep content clear of UI overlays |
| Facebook profile | 1080 x 1080 | Centered mark; circular-crop safe |
| Facebook cover | 1640 x 624 | White lockup on Ink; center-safe across mobile/desktop crops |
| X profile | 1080 x 1080 | Centered mark; circular-crop safe |
| LinkedIn company profile | 1080 x 1080 | Centered mark |
| LinkedIn cover | 2256 x 382 | White lockup on Ink; keep left profile overlap clear |
| TikTok profile | 1080 x 1080 | Centered mark; circular-crop safe |
| WhatsApp Business profile | 1080 x 1080 | Centered mark; circular-crop safe |
| YouTube profile | 1080 x 1080 | Centered mark; circular-crop safe |
| YouTube channel banner | 2560 x 1440 | Critical artwork inside central 1546 x 423 safe area |

Do not invent campaign copy. Recheck platform specifications at production time because platform crops can change.
