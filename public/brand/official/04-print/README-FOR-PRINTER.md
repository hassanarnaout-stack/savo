# README FOR PRINTER

Use `SAVO-Logo-Master-Outlined-RGB.ai` or its vector PDF. The outlined RGB master is immutable. Do not redraw, typeset, recolor, stretch, crop, rearrange, simplify or add effects.

- Clear space: at least 25% of displayed S-mark width on every side.
- Minimum lockup: 32 mm wide.
- Minimum mark: 8 mm square.
- CMYK: derive only from a duplicate using the agreed device/substrate ICC profile.
- Pantone: not assigned; physical swatch and production proof approval required.
- Confirm bleed, trapping, overprint, black construction and white ink.
- Send digital and physical proofs before production.

See `CMYK-WORKFLOW.md`, `PANTONE-SPOT-COLOR.md` and `SAVO-PRINTER-HANDOFF.md`.
